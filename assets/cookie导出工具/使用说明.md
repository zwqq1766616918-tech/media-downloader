# Cookie 导出工具（国内离线版）

给「推特 / Instagram / 微博 / TikTok」导出 `cookies.txt` 用的。

本目录里放的是一份**已经打包好的扩展本体**，国内用户**不需要访问 Chrome 商店、不需要能上外网**，
用 Chrome 自带的「加载已解压的扩展程序」就能装上。

> 扩展原名：**Get cookies.txt LOCALLY** v0.7.2（开源，MIT 协议）
> 官方仓库：https://github.com/kairi003/Get-cookies.txt-LOCALLY
> 它的宣传语就是 **"Get cookies.txt, NEVER send information outside with open-source"** ——
> 扩展只在你本机读取 Cookie 并生成文件，**不会把任何数据发到外面**。

## 二、第一步：确认有 Chrome 浏览器

本工具针对 **Chrome**（Edge 也同理，把下面所有 `chrome://` 换成 `edge://` 即可）。

- **有 Chrome** → 直接跳到第三节
- **没有 Chrome** → 国内不用外网也能装，三条路任选：

  | 方式 | 地址 | 说明 |
  | --- | --- | --- |
  | Chrome 官方中国站（离线包，推荐） | `https://www.google.cn/chrome/?standalone=1&platform=win64` | 带上 `standalone=1` 参数才是**离线安装包**，装的时候不用联网 |
  | 国内镜像（阿里 npmmirror） | `https://registry.npmmirror.com/binary.html?path=chrome-for-testing/` | 进 `win64` 目录下 `chrome-win64.zip`，解压即用，纯国内直连 |
  | Microsoft Edge（系统多半自带） | `https://www.microsoft.com/zh-cn/edge` | Win10/11 通常已预装，可直接用它，无需再装 |

  > ⚠️ 如果 `google.cn` 打不开，**直接用第二条国内镜像**，它由阿里托管，国内访问最快也最稳。
  > 镜像里的是「Chrome for Testing」版本，功能和正式版一样，只是不自动更新，当浏览器用完全没问题。

装完后随便打开一个网页，确认浏览器能用。

## 三、第二步：离线安装扩展（推荐，全程不需要外网）

### 方法一：一键脚本（省事）

双击本目录下的 **`一键安装扩展.bat`**。它会：
1. 把扩展文件夹的完整路径复制到你的剪贴板；
2. 自动用 Chrome 打开扩展管理页。

然后按下面的 **第 3~5 步** 操作即可。

### 方法二：纯手动

1. 打开 Chrome，地址栏输入并回车：
   ```
   chrome://extensions
   ```
2. 打开页面**右上角**的「**开发者模式**」开关（变成蓝色/开启状态）。
3. 点左上角出现的「**加载已解压的扩展程序**」按钮。
4. 在弹出的文件夹选择框里，选中**本目录下的**这个文件夹：
   ```
   <本目录>\扩展_Get-cookies.txt-LOCALLY_v0.7.2
   ```
   ⚠️ 注意：要选**这个文件夹本身**，不是里面的 `manifest.json`。
   （`<本目录>` 就是你现在打开的这个 `cookie导出工具` 文件夹）
5. 点「选择文件夹」。列表里出现 **Get cookies.txt LOCALLY** 就成功了。
6. 建议点一下扩展卡片上的「详情」→ 打开「**固定到工具栏**」，方便以后点图标。

### 备选：能上外网的用户

如果这台电脑能访问 Chrome 商店，也可以直接装商店版（好处是自动更新）：
打开 `https://chromewebstore.google.com/` 搜索 **Get cookies.txt LOCALLY** → 添加到 Chrome。
功能与离线版完全一致。

## 四、第三步：导出 cookies.txt

### 通用步骤

1. 用 Chrome 打开**目标网站并登录**（例如 `https://x.com`）。
   > 扩展导出的是「**当前标签页所在网站**」的 Cookie，所以必须停在该网站的页面上。
2. 点浏览器右上角工具栏里的 **Get cookies.txt LOCALLY** 图标。
3. 弹出的面板里确认两处：
   - **Export Format** 选 **`Netscape`**（默认就是它，不要改成 JSON）
   - 面板顶部显示的网址，是你要导出的那个站
4. 点 **`Export`** 按钮，浏览器会下载一个文件，默认名叫 `<网站域名>_cookies.txt`。
5. 把这个文件**重命名为 `cookies.txt`**，放到下表对应的目录里（**覆盖**旧的）。

### 各平台对照表

| 平台 | 先在 Chrome 登录 | 导出的文件放到 |
| --- | --- | --- |
| 推特 X | `https://x.com` | `<工具目录>\twitter-tools\cookies.txt` |
| Instagram | `https://www.instagram.com` | `<工具目录>\instagram-tools\cookies.txt` |
| 微博 | `https://weibo.com` | `<工具目录>\weibo-tools\cookies.txt` |
| TikTok | `https://www.tiktok.com` | `<工具目录>\tiktok-tools\cookies.txt` |

> `<工具目录>` 指你自己放下载引擎的目录。**具体路径不用背**——
> 跑一次 `app/配置向导.bat`，它会把每个平台该放哪儿直接列出来。
> 如果这些 `xxx-tools` 目录还不存在，见 `references/环境准备.md` 第七节。

> **小红书不走这里**。小红书用扫码登录，跑 `xiaohongshu-mcp\1-扫码登录.bat`
> 用小红书 App 扫码即可，会自动生成 `cookies.json`。
>
> **抖音也不走这里**，用 MediaCrawler 扫码登录（首次采集时会弹浏览器）。

### 建议用小号

`cookies.txt` 等于你账号的钥匙，**导出后不要发给任何人、不要传网盘**。
推特/Instagram 建议专门注册一个小号来导出，避免主号被风控。

## 五、第四步：验证导出对不对

用记事本打开导出的 `cookies.txt`，应该能看到：

- 第一行是 `# Netscape HTTP Cookie File`
- 后面每行是 **7 列、用 Tab 分隔**，例如：
  ```
  .x.com	TRUE	/	TRUE	1790000000	auth_token	xxxxxxxx
  ```

**各平台必须包含的关键 Cookie**（缺了基本抓不到数据）：

| 平台 | 关键字段 |
| --- | --- |
| 微博 | `SUB`、`SUBP` |
| Instagram | `sessionid`、`csrftoken` |
| 推特 X | `auth_token`、`ct0` |
| TikTok | `sessionid`（或 `sid_tt`） |

如果导出的文件里一个都没有，多半是**没登录**或**停在了错误的分站**（比如停在 `m.weibo.cn` 而不是 `weibo.com`）。

## 六、常见问题

**Q：Chrome 商店打不开 / 转圈加载不出来？**
不用管，直接用本目录的**离线安装**方式（第三步方法一/二），完全不需要商店。

**Q：我下载到了 `.crx` 文件，双击装不上？**
Chrome 现在禁止安装商店以外的 `.crx`。改用「加载已解压的扩展程序」——把 `.crx` 用压缩软件解压成文件夹，再加载那个文件夹即可（本目录已经帮你解压好了，直接用 `扩展_Get-cookies.txt-LOCALLY_v0.7.2` 就行）。

**Q：每次启动 Chrome 都提示「请停用开发者模式扩展程序」？**
这是新版 Chrome 对开发者模式扩展的例行提醒。点 **「保留」/「Keep」** 即可，扩展会继续正常工作。

**Q：点 Export 没反应 / 下载不了文件？**
- 确认你停在的是**目标网站**的页面上（不能停在 `chrome://` 开头的内部页面）；
- 检查 Chrome 的下载设置，别把「下载前询问保存位置」之外的权限关掉了；
- 也可以改用面板里的 **`Copy`** 按钮，把内容复制出来，自己新建一个 `cookies.txt` 粘贴进去保存。

**Q：导出后平台还是报「Cookie 可能失效」？**
Cookie 会过期（尤其换网络、换 IP 后）。重新登录目标网站 → 再导出一次，覆盖旧文件即可。

**Q：扩展安全吗？会不会偷我的 Cookie？**
扩展本体是开源的（MIT 协议），权限只有 `cookies / downloads / activeTab / notifications`，
代码里没有任何把数据发往外部服务器的逻辑——所有处理都在你本机完成。
如果你不放心，可以用记事本打开 `扩展_Get-cookies.txt-LOCALLY_v0.7.2\modules\*.mjs` 自己看，全部源码就这几个文件。
