# 故障排查

先看界面顶部的**状态灯**：红灯鼠标放上去会显示原因，多数问题照着提示就能解决。
命令行下也可以随时体检：

```bash
python "app/配置向导.py" --check
```

---

## 一、启动类

### 双击 bat 一闪而过

先看是不是**端口 8790 已被占用**（说明服务已经在跑了，直接开浏览器就行）。
如果确实是启动失败，用记事本打开 `app/启动下载工作台.bat` 看有没有报错，
再检查技能目录下这两处是否完整：

- `runtime/python/python.exe`（自带便携 Python）
- `engines/`（自带下载引擎）

缺了说明包不完整，重新解压一份完整的技能包即可 —— **不需要**自己去装 Python。

### 提示「端口 8790 已被占用」

说明服务**已经在跑了**。直接打开 `http://127.0.0.1:8790` 即可，不要重复启动。
如果确实想重启：打开任务管理器结束 `python.exe`，再双击启动。

### 网页打不开 / 一片空白

1. 确认后台黑色窗口还在（关掉窗口 = 停服务）
2. 手动在浏览器输入 `http://127.0.0.1:8790`
3. 若仍不行，把黑色窗口里的报错内容记下来

## 二、Cookie 类（最常见）

### 提示「Cookie 可能失效」「未下载到文件」

Cookie 过期了。**重新登录目标网站 → 再导出一次 `cookies.txt` → 覆盖旧文件**。

导出时注意三点：

1. 必须**停在目标网站页面上**再点扩展（扩展导出的是当前标签页所在站）
2. 格式必须是 **Netscape**，不是 JSON
3. 文件名必须是 `cookies.txt`，放到技能目录的 `cookies/<平台>/` 下

### 放错地方了

四个平台的 Cookie 目录是固定的：

| 平台 | 正确位置 |
| --- | --- |
| 推特 X | `cookies/twitter/cookies.txt` |
| Instagram | `cookies/instagram/cookies.txt` |
| 微博 | `cookies/weibo/cookies.txt` |
| TikTok | `cookies/tiktok/cookies.txt` |

状态灯变绿才说明程序读到了这个文件。

### 导出的文件里没有关键字段

| 平台 | 关键字段 |
| --- | --- |
| 微博 | `SUB`、`SUBP` |
| Instagram | `sessionid`、`csrftoken` |
| 推特 X | `auth_token`、`ct0` |
| TikTok | `sessionid` / `sid_tt` |

一个都没有 → 多半是**没登录**，或停在了错误的分站
（例如停在 `m.weibo.cn` 而不是 `weibo.com`）。

### 扩展点了 Export 没反应

- 确认不是停在 `chrome://` 开头的内部页面（内部页面导不出来）
- 改用面板里的 **`Copy`** 按钮，把内容复制出来，自己新建 `cookies.txt` 粘贴保存

## 三、扩展安装类

### Chrome 商店打不开 / 转圈

不用管，用 skill 附带的**离线安装**方式（`assets/cookie导出工具/`），完全不需要商店。

### 下载到 `.crx` 双击装不上

Chrome 现在禁止安装商店以外的 `.crx`。改用「加载已解压的扩展程序」——
把 `.crx` 解压成文件夹再加载。skill 附带的已经是解压好的文件夹，直接用即可。

### 每次启动 Chrome 提示「请停用开发者模式扩展程序」

新版 Chrome 对开发者模式扩展的例行提醒，点「**保留**」即可，功能不受影响。

## 四、平台类

### 抖音：状态灯显示「未安装抖音补充包（可选）」

抖音走 MediaCrawler，体积约 600 MB，**没放进主包**。要装的话在技能目录下执行：

```bash
python tools/打包-抖音补充包.py
```

打完再跑一次配置向导即可。**不想用抖音就忽略这条**，其它五个平台不受影响。

### 抖音：状态灯显示「缺少浏览器」

抖音需要一个真实浏览器来生成签名、保存扫码登录态。本包**不再自带浏览器内核**
（那样要多占 400 多 MB），改用用户本机已装的 Chrome / Edge。

双击 `app/安装浏览器.bat`：脚本会先自动检测，找到了直接提示「无需再装」；
没找到就给三种办法（用自带的 Edge / 装官方 Chrome 离线包 / 下便携版解压到
`browser\` 目录）。装好后再双击一次让它确认，状态灯就会变绿。

### 抖音：单条作品下不到

主页和单条都支持，先确认链接形态：

- 单条：`https://www.douyin.com/video/<数字>`、`/note/<数字>`、
  `https://v.douyin.com/xxxx/` 分享短链，或直接粘那串纯数字 ID
- 主页：`https://www.douyin.com/user/MS4wLjABAAAA...`

如果链接没错还是没下到，多半是**没登录**或**被风控**：
先双击 `engines/mediacrawler/3-下载抖音单条作品.bat` 手动跑一次，
弹出浏览器后用抖音 App 扫码登录，成功一次之后界面里再试。

### 抖音：提示「未采集到媒体」

按可能性排序：该主页没有作品 → 没登录 → 被风控。
先手动跑一次 `engines/mediacrawler/2-采集抖音作者主页.bat` 扫码登录，再重试。

### 抖音：报 execjs / 找不到 Node / RuntimeUnavailable

MediaCrawler 用 execjs 跑 `libs/douyin.js` 生成签名参数，execjs 默认去 PATH 找 `node`。
**用户电脑上不需要装 Node** —— 补充包里 Playwright 的驱动自带一个 `node.exe`：

```
runtime/pkgs/mediacrawler/playwright/driver/node.exe
```

工作台和两个启动 bat 都会自动把这个目录加到 PATH 最前面。出现这个报错说明：

1. 补充包不完整（`runtime/pkgs/mediacrawler/playwright/driver/node.exe` 丢了）→ 重新打包一次
2. 或者是手动在命令行跑 `main.py`、没经过启动脚本 → 双击 bat 跑，或自己先
   `set PATH=<技能目录>\runtime\pkgs\mediacrawler\playwright\driver;%PATH%`

### 抖音：扫码后卡在滑块 / 手机号验证

MediaCrawler 的浏览器窗口是**可见**的，手动拖一下滑块、完成手机号验证即可，
不要急着关窗口。

### 小红书：提示「MCP 服务未启动」

双击 `engines/xiaohongshu-mcp/2-启动MCP服务.bat` 保持服务运行。
如果启动不了，先跑 `1-扫码登录.bat` 重新扫码。

### 小红书：下载中途报登录失效

登录态过期，重新跑 `engines/xiaohongshu-mcp/1-扫码登录.bat` 扫码。

### TikTok：报 403 / 未产生文件

TikTok 的 CDN 对机房 IP 会直接拒绝。确认：

1. 自带运行时完好（`runtime/pkgs/gallerydl/` 里有 `yt_dlp` 和 `curl_cffi`）
2. `cookies/tiktok/cookies.txt` 没过期（TikTok 的 Cookie 在机房 IP 下过期较快）
3. 有条件的话换一个网络出口节点

### Instagram：什么都没下到

Instagram 自 2023 年起几乎全部内容要求登录。确认 `cookies/instagram/cookies.txt` 有效；
如果该主页是**私密账号**，还需要该账号是你的关注对象。

### 微博：抓到的数量比预期少

微博提取器不支持 `max-posts`，程序改用 `--range`。如果数量异常，先清空「数量上限」再试。

## 五、界面类

### 顶部一直是红灯

鼠标悬停在红灯上，会显示具体缺什么（例如「缺少 cookies.txt」「MCP 服务未启动」）。
按提示补齐后，状态灯 2 秒内会自动变绿。

### 点「选择文件夹」没弹窗

个别精简版系统缺少 `tkinter`。直接在输入框里手动粘贴路径即可（例如 `D:\我的下载`）。

### 想换保存位置

点「选择文件夹」，或直接把路径粘到输入框。默认位置是 skill 目录下的 `下载/`。

## 六、分享给他人时

技能包**出厂时就不含**任何个人数据，可以直接分享。分享前只确认这三项不存在：

1. `config.json`（里面记着本机路径）
2. `运行记录/`（任务历史与日志）
3. `下载/`（下载下来的内容）

另外 `cookies/` 里如果有你自己导出的 `cookies.txt`，也要一并删掉再分享。

对方拿到后双击 `app/配置向导.bat` 就能用，**不需要装 Python 或任何下载引擎**。
装了抖音补充包的，把 `runtime/python311/` 和 `engines/mediacrawler/` 一起带上即可
（**不含浏览器内核**，对方电脑上有 Chrome 或 Edge 就能跑）。
