# 环境准备（国内无外网版）

这份文档假设用户**连不上外网**。下面所有下载地址都是国内可直连的，或者已经随 skill 附带。

**一句话总结**：用户只需要装一个浏览器，再导出 Cookie。
**不需要装 Python**，**不需要装任何下载引擎** —— 技能包自带便携运行时和全部引擎。

---

## 一、装浏览器

需要 **Chrome 或 Edge**（两者操作几乎一样，下文以 Chrome 为例）。

| 浏览器 | 国内下载地址 | 备注 |
| --- | --- | --- |
| Google Chrome（离线安装包） | `https://www.google.cn/chrome/?standalone=1&platform=win64` | 官方中国站；带 `standalone=1` 才是离线包，装时不用联网 |
| 国内镜像（阿里 npmmirror） | `https://registry.npmmirror.com/binary.html?path=chrome-for-testing/` | 进 `win64` 目录取 `chrome-win64.zip`，解压即用，纯国内直连 |
| Microsoft Edge | `https://www.microsoft.com/zh-cn/edge` | Windows 10/11 一般自带，可直接用 |

> **给新手的最省事建议**：先在开始菜单搜一下 `Edge`，Win10/11 基本都自带，
> 有就直接用，连浏览器都不用装。真要装 Chrome 而 `google.cn` 打不开时，
> 让用户走第二行的 **npmmirror 镜像**（阿里托管，国内直连最快）。
> 镜像里是「Chrome for Testing」版，功能和正式版一致，只是不自动更新。

装完随便打开一个网页确认能用。

## 二、Python 与下载引擎：不用装

技能包自带：

```
runtime/python/          便携 Python 3.12（启动脚本优先用它）
runtime/pkgs/gallerydl/  gallery-dl + yt-dlp 及其依赖
runtime/pkgs/xhs/        小红书 XHS-Downloader 的依赖
engines/tiktok/          TikTok 下载器
engines/xhs-downloader/  小红书 XHS-Downloader 源码
engines/xiaohongshu-mcp/ 小红书 MCP 服务
```

启动脚本会**优先使用自带的 `runtime/python/python.exe`**，
只有这个文件不存在时，才会退回去找用户本机装的 Python。

> 所以用户电脑上有没有 Python、有没有装过 pip 包，都不影响使用。
> 配置向导也不会去扫描用户硬盘 —— 自带件齐全时它直接生成配置。

## 三、装 Cookie 导出扩展（离线，不用商店）

扩展本体已随 skill 附带，**不需要访问 Chrome 商店**：

```
assets/cookie导出工具/扩展_Get-cookies.txt-LOCALLY_v0.7.2/
```

### 安装步骤

1. 双击 `assets/cookie导出工具/一键安装扩展.bat`
   （它会：把扩展文件夹路径复制到剪贴板 → 自动打开 `chrome://extensions`）
2. 打开页面**右上角**的「**开发者模式**」
3. 点左上角「**加载已解压的扩展程序**」
4. 在文件夹选择框里，地址栏粘贴（`Ctrl+V`）刚复制的路径，回车
5. 点「选择文件夹」。列表出现 **Get cookies.txt LOCALLY** 即成功
6. 点扩展卡片上的「详情」→ 打开「**固定到工具栏**」，方便以后点图标

### 手动安装（脚本不好用时）

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」
4. 选中 `assets/cookie导出工具/扩展_Get-cookies.txt-LOCALLY_v0.7.2` **这个文件夹本身**
   （注意：选文件夹，不是选里面的 `manifest.json`）

### 关于安全性

该扩展是开源的（MIT 协议），权限只有 `cookies / downloads / activeTab / notifications`，
代码里没有任何把数据发往外部服务器的逻辑，所有处理都在本机完成。
源码就在扩展目录的 `modules/*.mjs` 里，可以直接用记事本打开核对。

## 四、导出各平台 cookies.txt

### 通用步骤

1. 用 Chrome 打开目标网站并**登录**
2. **停在这个网站的页面上**（扩展导出的是「当前标签页所在网站」的 Cookie）
3. 点工具栏的 **Get cookies.txt LOCALLY** 图标
4. 确认面板里：
   - **Export Format** 选 **`Netscape`**（默认就是它，别改成 JSON）
   - 顶部显示的网址是你要导出的那个站
5. 点 **`Export`**，会下载一个 `<域名>_cookies.txt`
6. 把它**重命名为 `cookies.txt`**，放到下表对应目录（覆盖旧的）

### 放置位置

统一放在**技能目录下的 `cookies/`** 里，一个平台一个子文件夹：

| 平台 | 先登录 | 放到 |
| --- | --- | --- |
| 推特 X | `https://x.com` | `cookies/twitter/cookies.txt` |
| Instagram | `https://www.instagram.com` | `cookies/instagram/cookies.txt` |
| 微博 | `https://weibo.com` | `cookies/weibo/cookies.txt` |
| TikTok | `https://www.tiktok.com` | `cookies/tiktok/cookies.txt` |

> 这几个子文件夹由配置向导自动建好，里面还放了一份
> `cookies/把导出的文件放这里.txt` 提示，照着放就行。
> 文件名**必须**是 `cookies.txt`（不能是 `x.com_cookies.txt`）。

### 必须包含的关键字段

| 平台 | 关键字段 | 说明 |
| --- | --- | --- |
| 微博 | `SUB`、`SUBP` | 少了必然抓不到 |
| Instagram | `sessionid`、`csrftoken` | |
| 推特 X | `auth_token`、`ct0` | |
| TikTok | `sessionid` / `sid_tt` | |

### 建议用小号

`cookies.txt` 等于账号钥匙。**不要发给任何人、不要传网盘**。
推特 / Instagram 建议专门注册小号来导出，避免主号被风控。

## 五、小红书：扫码登录

小红书**不用**上面的扩展，走扫码：

1. 双击 `engines/xiaohongshu-mcp/1-扫码登录.bat`
2. 用**小红书 App** 扫码
3. 登录态会保存到本地，之后跑 `2-启动MCP服务.bat` 保持服务在运行

界面上的小红书状态灯变绿，才说明 MCP 服务和登录态都正常。

> 登录数据保存在技能目录的 `runtime/temp/rod` 下，不依赖系统临时目录，
> 所以不会被系统的磁盘清理顺手删掉。

## 六、抖音：补充包 + 扫码登录

抖音走 MediaCrawler，**需要先装「抖音补充包」**（体积约 600 MB，所以没放进主包）：

```
python tools/打包-抖音补充包.py
```

打完包再跑一次配置向导，抖音状态灯就会变绿。

抖音**需要电脑上有 Chrome 或 Edge**（用来生成请求签名、保存扫码登录态）。
本包**不再自带浏览器内核**（那样要多占 400 多 MB），直接复用用户自己装的浏览器。
没装的话，双击 `app/安装浏览器.bat`，脚本会先检测、没找到再给三种安装办法。

> 抖音的签名脚本要一个 JS 运行时，**不需要用户装 Node.js** ——
> 补充包里 Playwright 的驱动自带 `node.exe`，启动脚本会自动把它加到 PATH。

第一次采集时会**弹出浏览器窗口**，用抖音 App 扫码登录即可。
登录态会缓存在本地（`engines/mediacrawler/browser_data/`），之后一般不用重复登录。

**主页和单条都支持**：

- 作者主页链接（`/user/xxx`）→ 采集该博主全部作品
- 单条作品链接（`/video/xxx`、`/note/xxx`、`v.douyin.com` 分享短链、纯数字 ID）→ 只下载这一条

界面上粘贴什么链接都行，程序会自动分辨；也可以直接双击
`engines/mediacrawler/3-下载抖音单条作品.bat` 手动跑单条。

> 补充包里自带 Python 3.11，所以**不需要**装 uv，也不需要装 Python。
> 想删掉：`python tools/打包-抖音补充包.py --clean`

## 七、自检

双击 `app/配置向导.bat`（或命令行 `python "app/配置向导.py" --check`）。

体检结果里：

- `[√] 自带运行时` —— 说明便携 Python 和引擎都在
- 各平台标 `×` 的，就是还缺 `cookies.txt` 或还没扫码登录

全绿之后，双击 `app/启动下载工作台.bat` 就能用了。
